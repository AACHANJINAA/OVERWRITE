# Task Breakdown - SYSTEM::OVERWRITE

이 문서는 `docs/Game_GDD.md`를 작은 구현 단위로 나눈 목록입니다. STL 퍼즐의 실제 문제 내용은 `docs/STL_Problem.md`에서 관리하고, 이 문서는 어떤 단계에서 어떤 Problem을 게임에 구현할지만 참조합니다.

## 1주차 - 창, 렌더링, 3D 보드

### Task 01-1 - Windows OpenGL 창 생성
#### 원하는 동작
- 실행하면 검은 배경의 Windows 창이 열리고 OpenGL 렌더 루프가 동작한다.
#### 세부 설명
- 외부 프레임워크 없이 Win32 API + Windows 기본 OpenGL(`opengl32`) 흐름으로 구현한다.
- ESC 또는 창 닫기로 종료할 수 있어야 한다.
- 아직 3D 노드, UI, 사운드는 다루지 않는다.

### Task 01-2 - 네온 와이어프레임 콘솔 보드
#### 원하는 동작
- 우주선 메인 컴파일러 콘솔처럼 보이는 3D 와이어프레임 보드를 렌더링한다.
#### 세부 설명
- 바닥 격자, 중앙 회로판, 데이터 흐름 라인을 기본 도형과 선으로 표시한다.
- 정상 회로는 청록/푸른색, 경고 회로는 붉은색 계열로 구분한다.

### Task 01-3 - STL 노드 데이터와 기본 배치
#### 원하는 동작
- `STLNode` 데이터 배열을 기반으로 여러 STL 시스템 노드가 3D 공간에 배치된다.
#### 세부 설명
- 노드는 엔진, 포탑, 레이더 등 시스템 이름을 가진다.
- 버그 노드는 붉은색, 정상 노드는 푸른색으로 표시한다.
- 이 시점에는 클릭 선택과 상세 UI는 다루지 않는다.

## 2주차 - 카메라, 선택, UI

### Task 02-1 - 1인칭 이동과 시점 전환
#### 원하는 동작
- 1인칭 시점에서 `WASD`로 우주선 내부를 이동하고, 마우스 오른쪽 버튼 드래그로 시점을 전환한다.
#### 세부 설명
- 플레이어가 우주선 내부와 콘솔을 둘러볼 수 있는 기본 1인칭 조작을 구현한다.
- 상호작용은 `F`, 문제 풀이 선택은 마우스 왼쪽 클릭으로 분리한다.
- 복잡한 카메라 충돌이나 관성 연출은 제외한다.

### Task 02-2 - 마우스 노드 선택
#### 원하는 동작
- 화면의 노드를 클릭하면 선택 상태가 바뀐다.
#### 세부 설명
- 정확한 3D picking이 어렵다면 1차 프로토타입에서는 화면 좌표 근사 선택을 허용한다.
- 선택된 노드는 밝기 또는 외곽선으로 표시한다.

### Task 02-3 - 노드 상세 정보 UI
#### 원하는 동작
- 선택한 노드의 시스템 이름, 증상, 원인, 패치 후보가 화면에 표시된다.
#### 세부 설명
- 텍스트는 Win32/GDI 기반 또는 간단한 비트맵 폰트 방식으로 표시한다.
- UI는 읽기 쉬운 고정 패널 형태로 시작한다.

## 3주차 - STL Problem 구현

### Task 03-1 - STL_Problem Problem 001 구현
#### 원하는 동작
- `docs/STL_Problem.md`의 Problem 001 엔진 과열 문제를 게임 안에 구현한다.
#### 세부 설명
- 워프 엔진 제어부 노드를 선택하면 Problem 001의 증상, 원인, 패치 후보가 표시된다.
- 정답 패치 선택 시 엔진 노드가 정상화된다.
- 문제 텍스트와 오답 후보는 `STL_Problem.md`의 내용을 기준으로 한다.

### Task 03-2 - STL_Problem Problem 002 구현
#### 원하는 동작
- `docs/STL_Problem.md`의 Problem 002 포탑 먹통 문제를 게임 안에 구현한다.
#### 세부 설명
- 자동 포탑 타겟 배열 노드를 선택하면 Problem 002의 증상, 원인, 패치 후보가 표시된다.
- 정답 패치 선택 시 포탑 노드와 타겟 라인이 정상화된다.
- 문제 텍스트와 오답 후보는 `STL_Problem.md`의 내용을 기준으로 한다.

### Task 03-3 - STL_Problem Problem 003 구현
#### 원하는 동작
- `docs/STL_Problem.md`의 Problem 003 레이더 탐색 지연 문제를 게임 안에 구현한다.
#### 세부 설명
- 장거리 레이더 ID 탐색기 노드를 선택하면 Problem 003의 증상, 원인, 패치 후보가 표시된다.
- 정답 패치 선택 시 레이더 노드가 정상화된다.
- 문제 텍스트와 오답 후보는 `STL_Problem.md`의 내용을 기준으로 한다.

### Task 03-4 - STL_Problem 확장 문제 슬롯 구조
#### 원하는 동작
- `docs/STL_Problem.md`의 Problem 004 이후 문제를 나중에 쉽게 추가할 수 있는 문제 슬롯 구조를 만든다.
#### 세부 설명
- 1차 플레이에는 Problem 001~003만 필수로 활성화한다.
- Problem 004~008은 데이터로 등록 가능하되, 실제 스테이지 노출은 선택 구현으로 둔다.
- 새 문제를 추가할 때 렌더링/선택/UI 코드를 크게 바꾸지 않도록 문제 데이터와 노드 배치를 분리한다.

### Task 03-5 - 전체 수리 승리 흐름
#### 원하는 동작
- 모든 버그 노드가 정상화되면 마지막 버튼이 있는 통창 구역으로 진행할 수 있다.
#### 세부 설명
- 1차 기준으로 Problem 001~003이 모두 해결되면 우주선 정상화 상태로 전환한다.
- 바로 엔딩을 보여주지 않고, 지구가 보이는 통창 구역과 마지막 버튼을 활성화한다.
- 실패 조건은 이 단계에서 필수로 구현하지 않는다.

### Task 03-6 - 지구 통창과 마지막 버튼
#### 원하는 동작
- 모든 수리 완료 후 플레이어가 지구가 보이는 통창 구역에서 마지막 버튼을 누를 수 있다.
#### 세부 설명
- 우주선 외부 이동은 구현하지 않고, 기내 통창 너머에 절차적 지구를 표시한다.
- 버튼은 귀환 또는 항로 확정처럼 보이게 하며, 폭파 장치임을 누르기 전에는 직접 말하지 않는다.
- 지구와 통창은 이미지 없이 선, 원, 단순 다각형으로 표현한다.

### Task 03-7 - 지구 폭파와 외계인 반전 엔딩
#### 원하는 동작
- 마지막 버튼을 누르면 지구 폭파 애니메이션이 재생되고, 이후 검은 통창 반사 속 외계인 얼굴이 드러난다.
#### 세부 설명
- 폭파는 섬광, 충격파, 균열, 파편 라인으로 표현한다.
- 일정 시간 뒤 통창이 검게 변하고 우주복 헬멧 안의 외계인 실루엣이 나타난다.
- 외계인은 큰 눈, 좁은 턱, 미소 선으로 간결하게 표현한다.
- 모든 연출은 외부 이미지, 동영상, 대형 모델 없이 구현한다.

## 4주차 - 연출, 사운드, 마감

### Task 04-1 - XAudio2 경고음과 성공음
#### 원하는 동작
- 경고, 선택, 성공 상황에 맞는 간단한 사운드가 재생된다.
#### 세부 설명
- 대형 사운드 파일 대신 절차적 파형 또는 작은 PCM 데이터를 우선한다.

### Task 04-2 - 시각 피드백 강화
#### 원하는 동작
- 버그 노드, 선택 노드, 성공 노드의 시각 차이가 더 명확해진다.
#### 세부 설명
- 라인 밝기, 점멸, 간단한 글로우 느낌을 활용한다.
- 셰이더가 과해지면 고정 파이프라인 스타일 표현으로 낮춘다.

### Task 04-3 - 용량 점검과 제출 빌드
#### 원하는 동작
- 실행 파일과 필요한 리소스를 정리하고 제출 가능한 빌드를 만든다.
#### 세부 설명
- 1.44MB 목표를 기준으로 외부 리소스, 디버그 심볼, 불필요 파일을 점검한다.
- 게임이 처음부터 끝까지 끊기지 않고 진행되는지 확인한다.
