# Ending Sequence

## 목적
이 문서는 `SYSTEM::OVERWRITE`의 최종 반전 연출을 1.44MB 목표 안에서 구현하기 위한 기준입니다.

이미지, 동영상, 3D 모델 같은 대형 리소스 없이 OpenGL 기본 도형, 선, 색상, 시간 기반 애니메이션만으로 엔딩을 표현합니다.

## 핵심 반전
플레이어는 우주선을 수리해 지구로 향한다고 믿습니다.

하지만 모든 버그 수리를 마친 뒤 통창 앞의 마지막 버튼을 누르면, 버튼은 귀환 장치가 아니라 지구를 폭파시키는 장치였음이 드러납니다.

폭파 연출이 끝나고 창이 검게 변하면, 헬멧 유리에 비친 플레이어의 모습이 나타납니다. 우주복 안의 얼굴은 사람이 아니라 외계인이며, 외계인은 웃고 있습니다.

## 공간 범위
- 게임의 모든 조작과 상호작용은 우주선 내부에서만 이루어집니다.
- 플레이어가 우주선 밖으로 나가는 장면은 만들지 않습니다.
- 우주선 외부는 통창 너머의 원거리 배경으로만 표현합니다.
- 우주선의 전체 형태는 `docs/SPACESHIP_DESIGN.md`의 셔틀형 실루엣을 기준으로 가정하되, 1차 프로토타입에서는 내부 통로, 콘솔, 통창, 버튼만 구현합니다.

## 엔딩 흐름

### Phase 01. 모든 버그 수리 완료
- 모든 치명적 STL 노드가 정상화됩니다.
- 콘솔 보드의 붉은 라인이 푸른색/청록색으로 바뀝니다.
- 시스템 정상화 문구 또는 간단한 HUD 신호가 표시됩니다.
- 새로운 목적지가 나타납니다: 통창이 있는 우주선 내부 구역.

### Phase 02. 통창 구역으로 접근
- 카메라 또는 장면 전환으로 통창이 있는 내부 공간을 보여줍니다.
- 플레이어는 여전히 우주복 헬멧 안쪽 시점으로 봅니다.
- 통창 밖에는 지구가 보입니다.
- 지구는 이미지가 아니라 절차적 도형으로 표현합니다.

### Phase 03. 마지막 버튼
- 통창 앞 또는 옆에 마지막 버튼이 표시됩니다.
- 버튼은 처음에는 귀환, 항로 확정, 점프 준비처럼 보이는 중립적 의미를 가집니다.
- 문구는 직접적으로 "폭파"를 말하지 않습니다.
- 플레이어가 버튼을 누르면 엔딩 애니메이션이 시작됩니다.

### Phase 04. 지구 폭파
- 지구 중심에서 강한 빛이 퍼집니다.
- 원형 파동, 파편 라인, 붉은 섬광으로 폭파를 표현합니다.
- 대형 이미지나 파티클 텍스처 없이 `GL_LINES`, `GL_LINE_LOOP`, 단순 삼각형/사각형, 색상 변화로 처리합니다.
- 사운드가 들어간다면 저용량 절차적 폭발음 또는 짧은 노이즈를 사용합니다.

### Phase 05. 통창 암전
- 폭파 후 일정 시간이 지나면 통창이 검게 변합니다.
- 바깥 우주와 지구가 사라지고 검은 반사면처럼 보입니다.
- 헬멧 유리 반사와 통창 반사가 겹치며 플레이어 자신의 실루엣을 보여줄 준비를 합니다.

### Phase 06. 외계인 정체 공개
- 검은 창에 우주복 상반신 또는 헬멧 속 얼굴 실루엣이 비칩니다.
- 얼굴은 사람의 얼굴이 아니라 외계인 형태입니다.
- 큰 눈, 얇은 턱, 비정상적인 두상, 미소 곡선만으로 표현합니다.
- 마지막 프레임에서 외계인의 미소가 강조되고 게임이 끝납니다.

## 리소스 없이 가능한 표현

### 지구
이미지를 사용하지 않고 아래 도형으로 표현합니다.

- 푸른 원 또는 구체 느낌의 원형 라인
- 대륙은 불규칙한 초록/청록 라인 또는 작은 다각형
- 구름은 흰색의 얇은 곡선 라인
- 대기권은 옅은 파란 외곽 원
- 지구 자전은 대륙 라인을 천천히 이동시키는 방식으로 흉내냅니다.

1차 구현에서는 완전한 구체가 아니어도 됩니다. 통창 밖에 "지구로 읽히는 푸른 행성"이면 충분합니다.

### 폭파
대형 폭발 이미지를 쓰지 않습니다.

- 중심 섬광: 흰색/노란색 원이 빠르게 커졌다 사라짐
- 충격파: 여러 개의 원형 라인이 바깥으로 확산
- 균열: 지구 표면에 빨간 선이 갈라짐
- 파편: 짧은 선 조각들이 바깥으로 튐
- 암전: 전체 외부 창 영역을 검은 사각형으로 덮음

### 외계인 반사
텍스처 없이 실루엣으로 표현합니다.

- 헬멧 내부 얼굴 윤곽: 어두운 타원
- 눈: 큰 타원 두 개
- 미소: 얇은 곡선 느낌의 라인
- 머리: 사람보다 큰 위쪽 타원
- 턱: 좁고 긴 아래쪽 실루엣

OpenGL 고정 파이프라인 기준에서는 곡선을 여러 개의 짧은 선분으로 근사합니다.

### 우주복 느낌
이미지 없이 아래 요소만 사용합니다.

- 헬멧 바이저 반사 라인
- 어깨 실루엣
- 가슴 장치 느낌의 작은 사각형/원
- 장갑이나 팔은 1차 엔딩에서는 생략 가능

## CPU와 GPU 책임

### CPU 책임
- 엔딩 phase 관리
- 모든 버그 수리 여부 확인
- 마지막 버튼 활성화
- 버튼 입력 처리
- 엔딩 타이머 관리
- 지구 폭파 진행도 계산
- 창 암전 진행도 계산
- 외계인 반사 등장 진행도 계산

### GPU/렌더링 책임
- 통창 내부 공간 렌더링
- 지구 도형 표시
- 폭파 섬광, 충격파, 파편 표시
- 창 암전 표시
- 외계인 실루엣 표시
- 헬멧 유리 반사 오버레이 표시

게임 규칙, 버튼 판정, 엔딩 phase 전환은 Shader 또는 렌더 함수에서 직접 결정하지 않습니다.

## 필요한 데이터 구조 후보

```cpp
enum ENDINGPHASE
{
    ENDINGPHASE_NONE,
    ENDINGPHASE_APPROACH_WINDOW,
    ENDINGPHASE_WAIT_BUTTON,
    ENDINGPHASE_EARTH_EXPLOSION,
    ENDINGPHASE_WINDOW_BLACKOUT,
    ENDINGPHASE_ALIEN_REFLECTION,
    ENDINGPHASE_COMPLETE
};
```

```cpp
struct ENDINGSTATE
{
    ENDINGPHASE phase;
    float phase_time;
    float explosion_progress;
    float blackout_progress;
    float reflection_progress;
    bool is_final_button_pressed;
};
```

## 구현 후보 파일
- `2.Manager/EndingManager.*`: 엔딩 phase와 버튼 입력 흐름 관리
- `1.Component/EndingRenderComponent.*`: 통창, 지구, 폭파, 반사 실루엣 렌더링
- `1.Component/HelmetOverlayComponent.*`: 현재 `OpenGlRenderComponent`의 헬멧 유리 표현이 커질 경우 분리

1차 구현에서는 파일을 바로 늘리기보다, 엔딩 구현 시점에 필요한 만큼 분리합니다.

## 1.44MB 기준 판단

가능합니다.

가능한 이유:
- 지구는 원, 선, 단순 다각형으로 표현 가능
- 폭발은 색상 변화와 선 확산으로 표현 가능
- 외계인은 실루엣과 간단한 얼굴 선으로 표현 가능
- 우주복은 전체 모델이 아니라 반사 실루엣으로만 표현 가능
- 사운드는 파일 대신 절차적 PCM 또는 생략 가능

주의할 점:
- 이미지 텍스처를 쓰면 용량 목표를 빠르게 초과할 수 있습니다.
- 복잡한 3D 우주복 모델은 사용하지 않습니다.
- 대륙 모양을 너무 상세하게 만들지 않습니다.
- 폭파 애니메이션은 짧고 상징적으로 처리합니다.

## 연출 톤
- 처음에는 "귀환" 또는 "항로 복구"처럼 보이게 합니다.
- 마지막 버튼은 의심스럽지만 명확한 악의는 드러내지 않습니다.
- 지구 폭파 순간에 플레이어가 뒤늦게 의미를 깨닫게 합니다.
- 외계인 미소는 과장된 공포보다 조용한 반전으로 표현합니다.
- 엔딩 후 긴 설명문보다 짧은 암전과 실루엣을 우선합니다.
