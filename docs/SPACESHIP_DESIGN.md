# Spaceship Design

## 목적
이 문서는 `SYSTEM::OVERWRITE`에 등장하는 우주선의 외형과 내부 공간 기준을 정의합니다.

우주선은 플레이어가 수리하고 조작하는 주요 무대이며, 모든 플레이는 우주선 내부에서만 진행됩니다.

## 외형 기준
우주선은 셔틀형 우주선 실루엣을 기준으로 합니다.

주요 특징:
- 길고 날렵한 흰색 동체
- 앞쪽으로 뾰족하게 이어지는 기수
- 기수 상단 또는 전면부에 검은색 통창
- 좌우로 펼쳐진 삼각형 계열의 날개
- 뒤쪽에 작은 꼬리 날개 또는 안정판
- 후방 중앙 추진구
- 추진 시 뒤쪽으로 강한 흰색/노란색 화염 또는 광선이 뻗어나감

## 전면 통창
우주선 앞쪽의 검은 통창은 엔딩 연출에서 가장 중요한 공간입니다.

역할:
- 플레이어가 우주선 내부에서 지구를 바라보는 창
- 모든 수리 완료 후 마지막 버튼이 배치되는 구역
- 지구 폭파 후 검게 변하며 플레이어의 정체를 비추는 반사면

표현 기준:
- 외부에서는 검은색 또는 어두운 청회색 유리처럼 보입니다.
- 내부에서는 큰 파노라마 창처럼 보이며, 지구가 창 너머에 보입니다.
- 엔딩 후반에는 바깥 풍경이 사라지고 검은 거울처럼 변합니다.
- 이 반사면에 우주복 헬멧 안의 외계인 얼굴이 드러납니다.

## 내부 공간 범위
게임의 모든 조작과 상호작용은 우주선 내부에서 이루어집니다.

필수 내부 구역:
- 메인 컴파일러 콘솔 구역
- STL 버그 수리 회로 보드
- 통창 구역
- 마지막 버튼 패널

선택 내부 구역:
- 짧은 연결 통로
- 함교 벽면 와이어프레임 장식
- 엔진 상태 패널
- 경고등 또는 시스템 표시 라인

## 통창 구역
통창 구역은 수리 완료 후 이동하거나 장면 전환으로 도달하는 최종 구역입니다.

구성:
- 전면에 넓은 통창
- 통창 너머에 지구
- 통창 앞쪽 또는 오른쪽에 마지막 버튼 패널
- 바닥과 벽은 기존 콘솔 구역과 같은 네온 와이어프레임 스타일

플레이 흐름:
1. 모든 STL 버그를 수리합니다.
2. 통창 구역이 활성화됩니다.
3. 플레이어는 지구가 보이는 창 앞에 도달합니다.
4. 마지막 버튼을 누릅니다.
5. 지구 폭파 연출이 시작됩니다.
6. 통창이 검게 변합니다.
7. 외계인 얼굴 반사가 드러납니다.

## 외부 우주선 표현
1차 프로토타입에서는 우주선 전체 외부 모델을 만들지 않습니다.

이유:
- 게임 범위가 우주선 내부로 제한되어 있습니다.
- 1.44MB 목표 때문에 대형 모델이나 이미지 리소스를 사용하지 않습니다.
- 외형은 문서 기준으로 유지하고, 실제 플레이 화면은 내부 공간과 통창 연출에 집중합니다.

필요할 경우 외부 우주선은 엔딩 또는 시작 화면에서 아래 방식으로만 간단히 표현합니다.

- 흰색 선으로 그린 셔틀 실루엣
- 검은 통창 영역
- 삼각형 날개 라인
- 후방 추진광 라인

## 색상과 재질 느낌
- 동체: 흰색, 은색, 옅은 청색
- 통창: 검은색, 어두운 청회색, 반사광
- 추진광: 흰색, 노란색, 옅은 주황색
- 내부 콘솔: 검은 배경, 청록 라인, 붉은 경고 라인
- 엔딩 암전 통창: 거의 검은색, 약한 반사광

## 구현 기준
- 우주선 외형 이미지는 빌드에 포함하지 않습니다.
- 내부 통창과 버튼은 기본 도형과 선으로 구현합니다.
- 지구는 절차적 원, 선, 단순 다각형으로 표현합니다.
- 우주선 외부 실루엣이 필요하면 `GL_LINES` 기반으로 단순화합니다.
- 최종 반전은 통창 반사와 외계인 실루엣으로 전달합니다.
