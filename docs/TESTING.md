# Testing

## 목적
이 문서는 구현 후 검증 기준을 정의합니다.

## 검증 원칙
각 단계 구현 후 아래 순서로 확인합니다.

1. 관련 코드 수정 완료 여부 확인
2. 로컬 빌드 또는 정적 점검
3. `docs/STYLEGUIDE.md` 기준 위반 여부 확인
4. 현재 단계의 구현 범위와 완료 조건 일치 여부 확인
5. 진행 현황 문서 갱신

## 실행 확인 모드
기본 실행 확인 모드는 `수동 실행 확인`입니다.

- `수동 실행 확인`: 에이전트는 코드와 확인 절차를 준비하고, 사람은 실제 실행 결과를 확인합니다.
- `에이전트 확인`: 사용자가 요청하거나 자동 확인이 적절할 때 빌드/실행을 에이전트가 수행합니다.

## 수동 확인 예시
- 실행 파일이 정상적으로 열린다.
- 창 닫기 또는 ESC 종료가 동작한다.
- 3D 보드가 보인다.
- 마우스 조작이 기대대로 동작한다.
- 버그 노드 선택과 패치 판정이 정상이다.
- 모든 버그 수리 후 성공 결과가 표시된다.
